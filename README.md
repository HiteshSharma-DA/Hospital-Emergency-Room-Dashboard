# Hospital Emergency Room Dashboard

## Project Overview
This Excel dashboard analyzes Emergency Room (ER) data and provides insights into patient flow, waiting times, satisfaction levels, and department referrals.

## Key KPIs

### Number of Patients
- Total patients visiting the ER.
- Daily trend visualization using sparklines.

### Average Wait Time
- Tracks average waiting time before seeing a medical professional.
- Helps identify operational bottlenecks.

### Patient Satisfaction Score
- Measures patient experience and service quality.
- Trend analysis highlights changes over time.

## Additional Analysis
- Admission vs Non-Admission Status
- Gender-wise Analysis
- Age Group Distribution
- Department Referrals
- On-Time vs Delayed Attendance
